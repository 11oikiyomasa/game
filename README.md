# Dice Roguelike Board RPG

This repository is the implementation target for the Mini Tales-inspired original dice-based roguelike board RPG defined by the master specification provided with this project.

## Current status

The repository was initially empty. The project foundation is being established incrementally, following the required development phases rather than creating placeholder gameplay.

## Source of truth

The master game specification defines the required gameplay loop, architecture, systems, development phases, acceptance criteria, testing requirements, and implementation behavior.

## Target

- Android
- Mobile portrait
- Touch-first
- Mid-range devices
- Offline-compatible core gameplay where practical

## Development rule

Implement the smallest correct playable system first, test it, then expand it. Do not present incomplete or mocked functionality as complete.
